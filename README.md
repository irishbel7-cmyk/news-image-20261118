Sums up the world news of Wednesday 18 November 2026 in one deterministic 1024x1024 PNG (`/output/entry.png`), drawn from fixed layout constants with Pillow. No network; two runs write identical bytes.

## Run

    python3 main.py   # writes /output/entry.png
